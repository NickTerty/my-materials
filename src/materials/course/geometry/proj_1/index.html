賽車線與曲率 κ(s)

簡化模型：以直線＋圓弧組成賽道，單位為公尺，非真實座標。

先讀這裡：數學定義 → 對應到 F1
第一步　抽象幾何：平面曲線 r(s) = (x(s), y(s))，s 為弧長
  • T（單位切向量）：T = r′(s)，長度為 1，指向曲線前進的方向。
  • κ（曲率）：κ = |T′|，代表切線方向隨弧長「轉得多快」。直線 κ = 0；半徑 r 的圓 κ = 1/r。座標式：κ = |x′y″ − y′x″| / (x′² + y′²)3/2。
  • N（單位法向量）：與 T 垂直，指向曲線彎向的那一側，並且 T′ = κN。
  • 密切圓：在 P 點與曲線位置、切線、曲率三者都相同的圓，圓心 = P + N/κ，半徑 R = 1/κ。
第二步　套用到 F1：這些符號各自代表什麼？
  • 曲線 r(s) ＝ 賽車重心走過的路線（賽車線）。
  • T ＝ 車頭／車速的方向；速度向量 = vT。
  • κ 與 R ＝ 彎有多「緊」。髮夾彎 R 小、κ 大；高速彎 R 大、κ 小；直線 R = ∞。
  • N ＝ 輪胎必須把車「拉向」的方向（向心方向）。加速度分成兩部分：a = (dv/dt)·T + κv²·N，沿 T 的是油門／煞車，沿 N 的是側向加速度 aN = κv²。
  • 速度上限：輪胎抓地有極限 aN ≤ amax，因此 v ≤ √(amax/κ) = √(amax·R)。R 越大，能過彎的速度越高。
  • 賽車線的目的：在白線與路緣石之間，讓路線最小的 R 盡量大（最大 κ 盡量小）。這就是「外-內-外」：入彎前靠外、彎心貼內、出彎再回外。貼內側雖然路徑短，但 R 變小，車速被迫降低。
